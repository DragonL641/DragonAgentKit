## Business Blue

适合：企业管理系统、SaaS 后台、内部工具

```
主题：浅色（白色内容区 + 可选深色侧边栏）
主色：#1890ff (蓝色)
辅助色：#faad14 (警告黄)、#52c41a (成功绿)、#ff4d4f (错误红)
背景：#f0f2f5
卡片：#ffffff，边框 #f0f0f0
文字：主 #262626，次 #8c8c8c
侧边栏：#001529 (深蓝)，文字 #ffffffb3
```

组件库：Ant Design
字体：-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif（Ant Design 默认）

## Tech Dark

适合：开发者工具、监控面板、技术产品

```
主题：深色
主色：#722ed1 (紫色) 或 #1890ff (蓝色)
辅助色：#13c2c2 (青色)、#eb2f96 (品红)
背景：#141414
卡片：#1f1f1f，边框 #303030
文字：主 #f0f0f0，次 #8c8c8c
强调渐变：#722ed1 → #1890ff
```

组件库：Ant Design（暗色主题）或自定义
字体：'JetBrains Mono', 'Fira Code', monospace（代码区）+ 'Inter', sans-serif（正文）

## Nature Green

适合：环保、健康、教育类产品

```
主题：浅色

侧边栏：#f6ffed (极浅绿)
```

## Minimal Light

适合：shadcn/ui 项目、现代 SaaS、简约风格

```
主题：浅色，极简
主色：#0a0a0a (接近黑色)
辅助色：#737373 (灰色)
背景：#ffffff
卡片：#fafafa，边框 #e5e5e5
文字：主 #0a0a0a，次 #737373
无彩色强调，纯黑白灰
```

组件库：shadcn/ui
字体：'Inter' + 'Geist Mono'

## Typography Quick Reference

| 风格 | 标题字体 | 正文字体 | 适合场景 |
|------|---------|---------|---------|
| 中文企业 | Noto Sans SC | Noto Sans SC | 国内企业管理系统 |
| 中文现代 | PingFang SC | PingFang SC | macOS 上的中文产品 |
| 英文技术 | Space Grotesk | Inter | 开发者工具、SaaS |
| 英文编辑 | Playfair Display | Source Sans 3 | 内容/媒体类 |
| 英文极简 | Geist | Geist Sans | shadcn/ui 生态 |
| 等宽代码 | JetBrains Mono | JetBrains Mono | 终端/代码类界面 |
