## Dashboard / Admin Panel

### Pattern A: Classic Sidebar + Cards
```
┌───────┬─────────────────────────────┐
│       │  Header (面包屑 + 用户头像)  │
│  Nav  ├─────────────────────────────┤
│       │  ┌─────┐ ┌─────┐ ┌─────┐   │
│ Side  │  │ KPI │ │ KPI │ │ KPI │   │
│ bar   │  └─────┘ └─────┘ └─────┘   │
│       │  ┌────────────┐ ┌───────┐  │
│ 固定  │  │  Chart     │ │ Table │  │
│ 240px │  │            │ │ Recent│  │
│       │  └────────────┘ └───────┘  │
└───────┴─────────────────────────────┘
适合：功能多、导航项多的管理系统
```

### Pattern B: Top Nav + Full Width
```
┌─────────────────────────────────────┐
│  Logo  Nav1  Nav2  Nav3     User    │
├─────────────────────────────────────┤
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐  │
│  │ KPI │ │ KPI │ │ KPI │ │ KPI │  │
│  └─────┘ └─────┘ └─────┘ └─────┘  │
│  ┌────────────────────────────────┐ │
│  │  Chart (full width)            │ │
│  └────────────────────────────────┘ │
└─────────────────────────────────────┘
适合：功能简单、优先展示数据
```

### Pattern C: Collapsible Sidebar
```
┌──┬──────────────────────────────────┐
│☰ │  Header                          │
│  ├──────────────────────────────────┤
│📊│                                  │
│👥│  Content (自适应宽度)              │
│⚙ │                                  │
│  │                                  │
└──┴──────────────────────────────────┘
适合：需要最大化内容空间的场景
展开时 240px，收起时 64px（只显示图标）
```

## List / CRUD Page

### Pattern A: Standard Table Page
```
┌─────────────────────────────────────┐
│  页面标题            [+ 新增] [导出]  │
├─────────────────────────────────────┤
│  [搜索关键词]  [状态▼]  [日期范围]    │
├─────────────────────────────────────┤
│  ☐ │ 名称 │ 状态 │ 创建时间 │ 操作  │
│  ☐ │ xxx  │ ✅  │ 2026-04 │ 编辑  │
│  ☐ │ xxx  │ ❌  │ 2026-03 │ 删除  │
├─────────────────────────────────────┤
│  共 50 条  < 1 2 3 4 5 >  每页[]条  │
└─────────────────────────────────────┘
```

### Pattern B: Card Grid List
```
┌─────────────────────────────────────┐
│  项目列表            [+ 新建]         │
├─────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │ 📁   │ │ 📁   │ │ 📁   │        │
│  │ Name │ │ Name │ │ Name │        │
│  │ desc │ │ desc │ │ desc │        │
│  └──────┘ └──────┘ └──────┘        │
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │ ...  │ │ ...  │ │ ...  │        │
└─────────────────────────────────────┘
适合：展示型内容（项目、文档、商品）
```

### Pattern C: Master-Detail Split
```
┌────────────────┬────────────────────┐
│  搜索           │  详情标题           │
│ ┌────────────┐ │                    │
│ │ Item 1 (选中)│ │  [完整详情内容]     │
│ │ Item 2     │ │                    │
│ │ Item 3     │ │  [操作按钮]         │
│ │ Item 4     │ │                    │
│ └────────────┘ │                    │
│  分页           │                    │
└────────────────┴────────────────────┘
适合：邮件、消息、订单等需要快速预览的场景
```

## Form Page

### Pattern A: Modal Form (Lightweight)
```
           ┌──────────────────┐
           │  新增用户    ✕    │
           ├──────────────────┤
           │  用户名          │
           │  [___________]   │
           │                  │
           │  邮箱            │
           │  [___________]   │
           │                  │
           │  角色            │
           │  [▼ 下拉选择 ]   │
           │                  │
           │  [取消]  [确认]   │
           └──────────────────┘
适合：字段少（<8）的创建/编辑
```

### Pattern B: Full Page Form (Complex)
```
┌─────────────────────────────────────┐
│  ← 返回    创建订单                  │
├─────────────────────────────────────┤
│  Step 1 ─── Step 2 ─── Step 3       │
├─────────────────────────────────────┤
│                                     │
│  ┌───────────── 基本信息 ──────────┐│
│  │  字段1    字段2                 ││
│  │  字段3    字段4                 ││
│  └────────────────────────────────┘│
│                                     │
│  ┌───────────── 商品明细 ──────────┐│
│  │  [+ 添加商品]                   ││
│  │  商品1  数量  单价  小计         ││
│  └────────────────────────────────┘│
│                                     │
│           [草稿]  [提交审核]         │
└─────────────────────────────────────┘
适合：字段多、有步骤、有分组
```

## Login / Auth Page

### Pattern A: Centered Card
```
┌─────────────────────────────────────┐
│                                     │
│         ┌───────────────┐           │
│         │    Logo        │           │
│         │               │           │
│         │  用户名        │           │
│         │  [________]   │           │
│         │  密码          │           │
│         │  [________]   │           │
│         │               │           │
│         │  ☐ 记住我      │           │
│         │  [登 录]       │           │
│         │               │           │
│         │  忘记密码？     │           │
│         └───────────────┘           │
│                                     │
└─────────────────────────────────────┘
```

### Pattern B: Split Screen
```
┌──────────────────┬──────────────────┐
│                  │                  │
│  Brand Area      │  Login Form      │
│  Logo            │                  │
│  Tagline         │  [用户名]         │
│  Illustration    │  [密码]           │
│                  │  [登录]           │
│                  │                  │
│  (深色/渐变背景)   │  (浅色背景)       │
└──────────────────┴──────────────────┘
适合：SaaS/ToC 产品，有品牌展示需求
```

## Settings Page

```
┌───────┬─────────────────────────────┐
│       │  Settings                    │
│  Nav  ├─────────────────────────────┤
│       │  [个人] [安全] [通知] [主题]  │
│ Side  ├─────────────────────────────┤
│ bar   │                             │
│       │  头像  [上传]                │
│       │  昵称  [___________]        │
│       │  邮箱  [___________]        │
│       │  语言  [▼ 中文]             │
│       │                             │
│       │           [保存更改]          │
└───────┴─────────────────────────────┘
适合：设置、个人中心、偏好配置
使用 Tabs 或左侧子导航切换设置分组
```
