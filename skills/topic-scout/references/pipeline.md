# 选题管道规则

本文档包含选题系统的完整执行规则，供 subagent 使用。

---

## 聚焦领域（优先级排序）

1. **Vibe Coding** — 自然语言编程、Cursor、Claude Code
2. **Claude 生态** — Claude Skill、MCP Server、Claude Code 技巧
3. **AI Agent** — 自动化工作流、n8n、Make
4. **AI 知识管理** — 第二大脑、PKM、Obsidian + AI
5. **模型更新** — GPT、Claude、Gemini 版本发布
6. **AI 新产品** — Product Hunt 上榜、独立开发者作品
7. **海外热点** — 行业大事件、收购、融资

---

## 采集规则

### 数据源（5 大类）

#### 一、AI 博主 / KOL 实践分享

搜索策略：搜索 AI 工具实践、工作流分享、技巧类内容

```
"Claude Code" OR "Cursor" tips tricks workflow <当前年月>
"AI coding assistant" best practices <当前年月>
AI agent automation workflow <当前年月>
```

重点关注：实操经验分享、工具对比、效率提升技巧

#### 二、创业公司 / 新产品发布

搜索策略：Product Hunt、Hacker News 的 AI 新品

```
Product Hunt AI tools launch <当前年月>
"Show HN" AI project <当前年月>
AI startup launch developer tools <当前年月>
```

提取：产品名 + 一句话描述 + 链接 + 热度

#### 三、模型厂商官方动态

| 厂商 | 搜索关键词 |
|------|-----------|
| Anthropic | "Claude" new feature OR update |
| OpenAI | "ChatGPT" OR "GPT" update |
| Google | "Gemini" update OR Google AI |
| xAI | "Grok" update |
| Mistral | site:mistral.ai |

#### 四、AI 研究 / 学术动态

```
AI research breakthrough <当前年月> DeepMind OR Meta OR Google
AI paper "large language model" <当前年月>
```

注意：不采集纯学术论文，只关注引发广泛讨论的

#### 五、技术社区讨论

搜索策略：Reddit、Hacker News 热门 AI 讨论

```
Reddit ClaudeAI OR ChatGPT OR LocalLLaMA hot discussion <当前年月>
Hacker News AI trending <当前年月>
```

### 采集要求

- **必须提取原文链接**：每条热点都要有具体 URL（不是主域名）
- 不采集重复/相似内容，合并同类
- 标注内容语言（中/英）
- 优先有实操价值的内容（教程、技巧、工具）
- 优先 24 小时内的内容

## 生成规则

### 筛选标准

#### 必须满足

- AI 相关（Vibe Coding / Claude / AI 工具 / AI 模型）
- 有明确的用户价值（能学到/能用到/能思考）
- 国内用户能理解和关注

#### 加分项

| 维度 | 高分 | 低分 |
|------|------|------|
| 热度 | 讨论量大、增长快 | 冷门、无人问津 |
| 时效 | 24 小时内 | 超过 3 天 |
| 独特性 | 有新角度可挖 | 已被写烂 |
| 可操作性 | 能给出具体方法 | 纯概念讨论 |

### 写作方式分类

根据内容特点选择：

1. **干货教程** — 有具体步骤可复现
2. **产品体验** — 新产品/新功能测评
3. **观点分享** — 趋势分析/行业洞察
4. **新技术突破** — 重大更新/技术解读

### 选题公式参考

#### 工具测评型
- 用了 X 天 [工具]，我发现 [意外收获]
- [工具] 的隐藏功能，90% 的人不知道

#### 方法论型
- 我用 [方法] 搞定了 [问题] 的完整流程
- [数字] 个让 [场景] 效率翻倍的技巧

#### 热点结合型
- [热点] 爆火，但大家忽略了这一点
- 从 [热点] 看 AI 编程的未来

#### 反共识型
- 别再 [常见做法] 了
- 为什么我不推荐 [热门事物]

#### 经验复盘型
- 做了 [数字] 个 [事情] 后，我总结的 [数字] 条教训
- 如果重来一次，我会 [改变]

### 生成输出格式

每个选题输出：

```markdown
### 选题 N：[标题]

**事件描述**
一句话说清楚发生了什么

**核心角度**
为什么值得写？独特切入点是什么？

**推荐标题**（3 个备选）
1. 标题 A
2. 标题 B
3. 标题 C

**写作方式**：干货教程 / 产品体验 / 观点分享 / 新技术突破

**预估热度**：⭐⭐⭐⭐⭐（1-5 星）
```

## 审核规则

### 必过项（一票否决）

| 检查项 | 不通过标准 |
|--------|-----------|
| 热度 | 讨论量 < 100 或无增长趋势 |
| 相关性 | 与 AI/编程/效率无关 |
| 时效性 | 超过 72 小时的旧闻 |
| 可写性 | 没有可操作的内容输出 |

### 评分项（满分 100）

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 独特角度 | 30% | 有无别人没写过的切入点 |
| 用户价值 | 25% | 读者能获得什么 |
| 国内适配 | 20% | 国内用户是否关注 |
| 标题吸引力 | 15% | 是否想点进去看 |
| 可操作性 | 10% | 能否快速高质量完成 |

**通过线：70 分**
- ✅ 70 分以上：通过，保存到选题库
- ⚠️ 50-69 分：待优化，给出修改建议
- ❌ 50 分以下：不通过，说明原因

### 常见不通过原因

1. **热度不够** — 源头讨论量低，无传播趋势 → 等热度起来或换热点
2. **没有独特角度** — 已有大量类似文章 → 找差异化切入点或放弃
3. **不符合国内用户关注** — 纯海外事件，无本土关联 → 找国内共鸣点
4. **纯蹭热点无干货** — 只是转述新闻，无增量信息 → 加入实操/测评/深度分析
5. **写作成本过高** — 需要大量调研或技术门槛高 → 简化范围或分拆系列

### 质量自检清单

- [ ] 标题有冲突感？（数字、对比、反差、疑问）
- [ ] 读者有痛点？
- [ ] 我有独特视角？
- [ ] 有具体案例？
- [ ] 能引发讨论？

5 条全中 = 必写 | 3-4 条 = 可写 | < 3 条 = 再想想

## 每日目标

- 采集：50+ 条热点（5 个分类）
- 生成：10 个选题方案
- 通过：3-5 个合格选题
- 保存：全部通过的选题存入选题库
