# Topic Scout - AI 选题系统

通过 subagent 执行选题管道，避免大量中间过程占用主对话上下文。

## 触发模式

| 用户说 | 模式 | 说明 |
|--------|------|------|
| "开始今日选题" | 完整流程 | 采集 → 生成 TOP10 → 审核 → 保存 |
| "今日AI热点" / "看看今天有什么热点" | 仅采集 | 列出热点，不生成选题 |
| "我有一个选题：xxx" | 单题分析 | 评估用户选题，给优化建议 |
| "推荐一些好的选题" | 快速推荐 | 基于近期热点推荐 3-5 个 |

## 调用方式

检测到触发词后，使用 Agent tool 派发 subagent：

```
Agent(
  subagent_type: "general-purpose",
  prompt: <模式指令> + "\n\n" + <pipeline规则>,
  run_in_background: true
)
```

**构建 prompt 的步骤：**

1. 读取 `${SKILL_DIR}/references/pipeline.md` 获取完整管道规则
2. 根据触发模式选择对应的模式指令（见下方）
3. 拼接：模式指令 + pipeline.md 内容，作为 subagent 的 prompt
4. 派发 subagent（后台运行）

### 模式一 prompt（仅采集）

```
你是AI热点采集助手。请执行以下任务：

1. 读取下方的「采集规则」部分
2. 使用 WebSearch 并行搜索各数据源
3. 按输出格式整理为结构化热点列表
4. 将结果保存到 ${obsidian_path}/今日热点-MMDD.md

只采集热点，不生成选题方案。
```

### 模式二 prompt（完整流程）

```
你是AI选题系统，执行完整选题流程：

1. 读取下方的完整管道规则
2. 第一步：使用 WebSearch 采集今日热点
3. 第二步：从热点中筛选 TOP10，生成选题方案（标题+角度+写作方式）
4. 第三步：对每个选题按审核标准评分，只保留 70 分以上的
5. 将通过的选题保存到 ${obsidian_path}/每日选题/ 目录
6. 最后返回摘要：通过数量 + 每个选题的一行描述

输出格式严格遵循管道规则中的模板。
```

### 模式三 prompt（单题分析）

```
你是选题审核专家。用户有一个选题需要分析：

【用户选题】
${用户输入的选题内容}

请执行：
1. 使用 WebSearch 搜索相关热点，验证该选题的热度和时效性
2. 按下方的「审核规则」评分（100分制）
3. 给出优化建议（角度调整、标题备选、写作方式推荐）
4. 如通过（≥70分），保存到 ${obsidian_path}/每日选题/ 目录
```

### 模式四 prompt（快速推荐）

```
你是AI选题顾问。请快速推荐3-5个选题：

1. 使用 WebSearch 搜索近期AI热点（每个数据源1-2个搜索即可）
2. 快速筛选最有价值的 3-5 个方向
3. 每个给出：一句话标题 + 为什么值得写 + 推荐写作方式
4. 不需要详细审核，给出简要理由即可
```

## 结果展示

subagent 返回后，在主对话中展示摘要：

```
**选题完成**

- 采集热点：XX 条
- 生成选题：XX 个
- 审核通过：XX 个（已保存到 Obsidian）

通过选题一览：
1. [标题] - XX分 - [写作方式]
2. [标题] - XX分 - [写作方式]
...
```

## 输出位置

```
~/Documents/obsidian/选题库/
├── 每日选题/
│   └── MMDD-选题名称.md    # 通过审核的选题
└── 今日热点-MMDD.md        # 热点采集结果（仅模式一）
```

## 快捷指令

| 指令 | 说明 |
|------|------|
| "继续" | 继续上次中断的流程 |
| "跳过" | 跳过当前选题 |
| "保存" | 直接保存当前选题 |
| "放弃" | 放弃当前选题 |
| "改角度" | 换个角度重新生成 |
| "展开写" | 基于选题开始写作 |
